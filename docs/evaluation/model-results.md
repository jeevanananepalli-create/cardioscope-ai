not evidence of clinical performance, and the models have not been externally validated.

## Data and validation

- 303 records: 242 development, 61 holdout (one patient-level split shared by all four models).
- Model selection: repeated stratified 5-fold cross-validation, 5 repeats, on the development set only, with preprocessing fitted inside each fold.
- The holdout set was evaluated once, after algorithm, calibration and threshold were fixed.
- `LAD`, `LCX`, `RCA` and `Cath` are never model inputs.
